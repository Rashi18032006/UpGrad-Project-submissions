# upGrad project submissions

Projects built for upGrad Campus courses.

| Project | What it is | Stack |
|---|---|---|
| [quora-simple](quora-simple/) | Quora-style Q&A REST API: sign-up and sign-in with JWT, questions, answers, and admin-only user deletion, split into controllers, services and DAOs | Java 17 · Spring Boot 3 · Spring Security · JPA · PostgreSQL · Flyway |

Setup and the full endpoint list are in each project's own README.

> The JWT signing key and database password are read from environment variables. Set `DB_PASSWORD` and `JWT_SECRET` before running.
